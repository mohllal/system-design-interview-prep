# Sensor Data Analytics

Design a system that ingests temperature data from sensors deployed across Europe, processes the incoming data, and makes it available for analytics and querying.

The system should be able to:

- Ingest temperature readings from a large number of sensors.
- Process and transform the incoming data.
- Store the processed data in a way that supports efficient analytical queries.
- Provide analytics and querying capabilities over the collected temperature data.
- Handle the scale and continuous stream of data generated by sensors across Europe.
